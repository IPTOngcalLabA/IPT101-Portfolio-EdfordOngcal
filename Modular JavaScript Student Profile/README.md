## Verification Questions (Answer Sheet)

### 1. What is the difference between a function parameter and a function argument?
>The differnce is that the parameter is basically the placeholder variable that put inside the parentheses when creating a function, while an argument is the actual value pass in when we call it.

### 2. How does the `this` keyword allow an object method to reference properties within the same object?
>When calling a method on an object, JavaScript uses this to point back to that exact object. That way, the method can easily read or change the object's own properties without needing to know its variable name.

### 3. Why is modularizing code using `import` and `export` useful in modern Javascript development?
> Modularizing JavaScript code using import and export keeps our code organized, reusable, and easier to maintain and we can focuse to the point.

### 4. Why is it important to run `git pull origin main` before creating new folders and pushing commits to your main repository?
> Running git pull origin main first ensures that our local device has the latest version of the code before we start adding new folders or files. This prevents Git from rejecting our push later and helps us avoid messy merge conflicts with updates that were already made to the repository
